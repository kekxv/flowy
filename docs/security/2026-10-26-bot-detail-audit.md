# 机器人与临时详情安全检查

检查范围：2026-10-26 提交的临时详情功能及其直接依赖的机器人指令、知识库访问规则和 Markdown 渲染。本次为本地代码审查与自动化攻击场景回归，不是线上渗透测试或全站安全认证。

## 已确认并修复

| 风险 | 触发方式 | 修复 |
| --- | --- | --- |
| 高：私有知识库越权 | 共同参与问题会把相关用户的私有知识库纳入搜索，精确标题和模糊搜索都可触发 | 搜索只接受本人、公开或明确授权协作者的页面；旧搜索入口也遵守相同规则 |
| 高：旧操作绕过当前角色 | 已有待选择的指派操作时，删除机器人用户或降级为 viewer 后仍可回复数字完成指派 | 数字续操作前重新读取用户并检查当前指令权限，拒绝时清理待操作状态 |
| 中：账号停用未同步到机器人 | 绑定的 Flowy 账号停用后，机器人映射仍能查询 | 查询机器人用户时同时检查所绑定账号的存在与启用状态 |
| 中：知识库结果未重新授权 | 搜索后页面转私有或协作权限移除，数字选择仍按原 ID 直接读取 | 选择结果时调用知识库访问权限查询；同时修复该路径处理器未初始化的异常 |
| 中：危险 Markdown URL 未过滤 | 自定义 urlTransform 覆盖了 react-markdown 的安全默认值，保留 data、vbscript 等危险协议 | URL 改写后统一经过 react-markdown 默认协议过滤，包含自定义转换结果；现代 React 会另行阻止 javascript URL，本次不声称已复现任意脚本执行 |
| 低：非法序号引发异常 | 超过 Python 整数转换限制的长数字或能通过 isdigit 的特殊字符 | 转换前限制为 ASCII 和有界长度；其余返回无效序号 |
| 中：内部异常泄露 | 处理器异常包含数据库地址、SQL 或上游凭据时直接回复用户 | 对用户返回固定错误提示，具体异常留在服务端日志 |

## 临时详情接口验证

- 使用 32 字节随机值生成 token，数据库检索使用 SHA-256 摘要与参数化查询。
- 只有完整、有效期内的原始 token 才返回正文；内部记录 ID、摘要、截断或篡改的 token、SQL 注入字符串和超长 token 均被拒绝。
- 过期请求返回 410；公开接口仅支持读取，POST 与 DELETE 返回 405。
- 响应设置 no-store，不返回 creator_id、记录 ID、token 摘要或加密 token。

## 边界与后续风险

- 详情 URL 是持链接访问的分享链接：任何拿到完整链接的人都可在有效期内读取。默认有效期 24 小时；这符合当前免登录分享设计，不等同于登录后逐人授权。
- 内容是生成时的快照。已生成链接不会因账号停用、知识库权限变更而自动撤销；本次修复阻止后续越权生成，但不会回收过去已分享的数据。若确认曾发生私有页面泄露，应由管理员撤销相应历史链接；目前尚无详情链接撤销管理入口。
- 本次未增加公开详情接口限流，部署层应根据实际访问压力设置限流；没有实施线上压测。
- 没有审计全站所有接口及依赖供应链；验证结果不能推导为不存在其他漏洞。
