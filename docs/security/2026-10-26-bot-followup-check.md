# 机器人与详情页追加检查

范围：机器人查询/选择分支、软件版本下载回复、临时详情渲染和仪表盘统计。检查保留上一轮安全修复，未提交或部署。

## 本轮确认并修复

1. 测试报告正文在申请主页面重复出现。现在申请与报告分开，完整报告在卡片弹窗中查看。
2. 切换临时详情 token 后残留上一条内容、旧报告弹窗或失效错误。页面按 token 重新建立状态。
3. 普通知识库中“测试报告”章节可能被误当成报告边界并截断。新测试详情加入明确标记，兼容旧测试申请结构；普通 Markdown 保留。无报告提示及无法解析成卡片的尾部正文保留在独立区域。
4. 问题 ID 前缀匹配多条时触发 MultipleResultsFound。现在返回候选列表，提示进一步明确查询。
5. `/test report #编号` 不能查询，带空格标题只查询第一个词。现在规范化完整查询参数；缺少编号或标题返回用法。
6. 超长消息按字节切分时丢失中文和表情。现在只在完整 UTF-8 字符边界拆分。
7. `/list` 图表和总数只统计最近 50 条，漏掉其余记录。现在数据库按相同过滤条件汇总所有匹配项，明细仍最多 50 条，趋势统计使用完整范围。
8. 异常仪表盘 JSON 通过部分校验后触发页面异常。现在校验统计项、明细、日期和数值类型，不合格内容回退为 Markdown。
9. 机器人日志的 flowy_user_id 误写成机器人映射 ID，无法对应实际用户。现在记录绑定的 Flowy 用户 ID；未绑定用户记录空值，保留微信用户 ID。

上一轮补丁另已修复知识库数字选择未初始化 handlers，以及当前角色、停用账号和知识库可见性检查遗漏。
