# Testing feature internationalization plan

**Goal:** Complete Chinese/English translations across the testing workflow, reports, print preview and chart insertion; detect missing keys and mismatched interpolation variables.

**Architecture:** Use existing i18next/react-i18next resources and translation hooks. Separate flat namespaces for pages, report components and chart editing, with shared translated status labels and language-aware dates. Keep user-authored Markdown/data unchanged. Independent file groups are delegated; root merges translation resources and verifies integration.

- [x] Audit existing locale key parity and hardcoded testing text; add failing English UI and resource/reference tests.
- [x] Translate testing pages, public collection and shared status labels/dates.
- [x] Translate reports, printing, chart dialog and renderer/error messages.
- [x] Merge resources; check key/interpolation parity, English UI, runtime language changes and remaining hardcoded text.
- [x] Run frontend tests, lint/build, browser language checks and independent review. Do not start application services.

- Initial locale files contained 640 leaf keys each but testing UI text was not connected to them.
- Completed locale files contain 955 keys per language, including chart editing, visual validation/errors, test workflow pages, report/print UI and missing legacy key definitions.
- Fixed a software category label that referenced a translation object instead of a string.
- Automated checks verify resource key/interpolation parity and every literal translation key referenced in application TypeScript/TSX.
- 130 frontend tests passed across 27 files; final production build, lint and diff whitespace checks passed.
- English UI tests cover the chart dialog, list/status switching, creation form, public collection, and preview regeneration on language change.
- Real Chromium: English chart controls/defaults contain no untranslated Chinese; English print preview contains translated headings and preserves authored content; switching an open preview to Chinese rebuilds all pages.
- Independent review approved with no critical or important issues. No application services were started.
